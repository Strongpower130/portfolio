# Portfolio Website

A modern, responsive portfolio website showcasing my work as a 1st year Computer Engineering student at Lehigh University.

## Features

✨ **Professional Design**
- Clean, modern interface with smooth animations
- Fully responsive design (mobile, tablet, desktop)
- Gradient color scheme with interactive elements

👤 **Profile Section**
- Dynamic GitHub profile picture integration
- Display of name, education, and university info
- Social media links

📄 **Resume Section**
- Education details
- Skills showcase
- Link to download full resume

🚀 **Projects Section**
- Showcase of academic and personal projects
- Direct links to GitHub repositories
- Project descriptions and tags

🔗 **Repository Links**
- Fyre Assignments: [https://github.com/Strongpower130/fyre-assignments](https://github.com/Strongpower130/fyre-assignments)

## How to Use

### Local Development

1. Open `index.html` in your browser, or
2. Use a local server:
   ```bash
   python -m http.server 8000
   # or
   npx http-server
   ```
   Then visit `http://localhost:8000`

### Customization

- **Edit your information**: Modify the HTML in `index.html`
- **Change colors**: Update CSS variables in `styles.css` (look for `:root`)
- **Add projects**: Add new project cards in the Projects section
- **Update resume**: Replace or link to your resume PDF

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - JavaScript for interactivity and GitHub integration
- `This be your resume..pdf` - Your resume document

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Gradients)
- JavaScript (Fetch API, Intersection Observer)
- Font Awesome Icons
